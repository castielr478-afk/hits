# BeatLab

Aplicativo web para criação de melodias e beats com recursos prontos para uso:

- Sequenciador de bateria de 16 passos (kick, snare, hi-hat e clap)
- Teclado virtual com instrumentos variados (formas de onda)
- Performance Pads com one-shots e FX (atalhos `1` a `8`)
- Controle de BPM (tempo)
- Gravação de voz via microfone com preview
- Download da gravação em `.webm`
- Salvar, carregar e reiniciar projeto (persistência local no navegador)
- Galeria de imagens criativas para inspiração visual

## Como executar

```bash
python3 -m http.server 4173
```

Abra `http://localhost:4173` no navegador.

## Atalhos de notas

- `A` = C
- `S` = D
- `D` = E
- `F` = F
- `G` = G
- `H` = A
- `J` = B

## Atalhos de Performance Pads

- `1` = Sub Drop
- `2` = Laser
- `3` = Reverse
- `4` = Stab
- `5` = Perc FX
- `6` = Noise Hit
- `7` = Glitch
- `8` = Impact

## Fluxo recomendado de uso

1. Monte seu groove no sequenciador.
2. Toque a melodia no teclado e complemente com pads.
3. Grave a voz por cima do beat.
4. Baixe a gravação final.
5. Salve o projeto para continuar depois.
